# Task11 独立审查上下文

本文件是需求上下文，不是结论；controller在任务完成后提供精确BASE/HEAD与diff。读取task-11-brief.md、正式子规格、task-11-report.md。关注唯一实体计数与真实来源，明确统计窗口、授权范围和完整性；工具调用/事件/重试不能冒充业务实体。Opportunity或Handoff记录不等于满足术语表五个条件的合格贸易机会；无资格证据则未知并列缺项。

费用、模型token、人工耗时必须有可信输入来源；等待时间不是人工工作耗时，cost_class不是实付费用，估算上下文不是实际usage。缺费率不得形成金额或单位合格机会成本，金额计算仅Money/Decimal。不为填指标造钱包/薪资系统/改历史事实。boss-only Run审计不因链接而向所有角色开放，精确对象链接须当前授权，失败只安全分类与引用。

只读审查、无子代理。完整diff顺序一次；截断函数按需补读；每个具名具体风险一次定向域外核对并报告文件/结果，禁止泛查。报告包含Spec、质量、分级问题和Cannot verify；不重复报告中的同版本测试，具体未覆盖风险才最小验证。全仓门禁属12，真实业务成绩/生产费用/多人认证不从受控结果推导。

## Global Constraints

- 根 `AGENTS.md` 的九条硬边界和逐次人工审批要求保持不变；进入实现目录前读所有生效的就近规则。
- 本轮先交付本机受控 Web；不实现 Tauri，不开展真实客户发送、供应商联系、采购或部署。
- 金额只用 Decimal；模型不输出最终金额和概率；事实、推断及客户表达结构分离。
- tenant、actor、scope、Provenance、审批结论、预算不能来自客户端自报或测试绕过。
- 保持 `apps → workflows / agent_runtime → domains → shared`；进程之间不得互导。
- 新外部工具使用 manifest + check + handler 插件；不往 Gateway 核心增加具体业务分支。
- 已有 Catalog 培养 Case 仍止于 queued；本轮不新增培养消费者或默认生产策略。
- 每批次保留有意义的失败测试与聚焦通过证据；全量测试在集成里程碑执行，未改代码且无新疑点时不重复跑。
- 所有新文档用中文；API 类型从 OpenAPI 生成，前端不手写重复业务 DTO。
- 本计划中的“新增路径/接口”为拟议实现，不表示文件或能力已经存在。未来批次先产出该批详细规格，再按测试推进，不凭这份总计划猜测跨域契约。
