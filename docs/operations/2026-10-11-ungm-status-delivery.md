- API 来源：保留密钥验证与已支持的额度查询。免密钥公开 API 仍属 API；额度未接入时不编造数值。
- 登录会话来源：尚未测试登录、登录有效、上次登录有效待复测、需要重新登录、网站拒绝访问而登录未知、暂时限流、暂时无法验证。
- 公开网页：网站尚未测试、可访问、待复测、要求登录、拒绝访问、限流或暂不可访问。当前其他公开网页的真实可用性检测尚未接入，显示尚未测试。

## UNGM 行为与线上验证

只有 UNGM 当前启用“测试登录”。显式点击后，经平台当前授权、CSRF 和独立 Gateway 插件，让服务器隔离浏览器关闭旧实例并用已保存的目标网站会话重开账户页。确认实际登录标志后返回固定分类与时间。不读取采购附件、不调用数据 API、不发送邮件。

北京时间 18:19:34，真实 xue 后台按钮测试返回“登录有效”。服务器从已保存会话恢复成功，没有重新输入密码或验证码。18:19:49 刷新来源列表，仍显示同一检查时间，说明读取快照没有再次访问 UNGM。

页面加载与刷新仅读取无凭证快照。检查结果在独立 `browser-ungm.json` 持久保存，权限 0600，绑定控制租户与工具审计引用；原 API 凭证与浏览器 Cookie 文件未读取或改写。一分钟内重复点击复用快照；成功超过一天仅标记待复测，不声称会话过期。403 与超时不误判为过期，只有真实登录页重定向才显示需要重新登录。

浏览器仍由原容器独立管理，主 API 不启动 Playwright、不读取 Cookie。部署绑定单独保存在私有 `ungm-browser-binding.json`，缺失、损坏或租户不匹配时关闭按钮。隔离服务仍仅映射服务器 loopback 8791；原 SSH 远程窗口可继续使用。试验服务的 30 次终身限制改为每小时最多 30 次，审计先 fsync 再执行，避免累计测试后永久停用。
