# 成本与报价启用和恢复

只覆盖Phase2成本报价批次：主流程止于approved及客户PDF交付，不自动发送、成交或履约。
受控测试不代替真实供应商资料、真实对象存储及Phase1运营验收。实际结果见[批次验收](../acceptance/2026-08-28-phase2-costing-quotation.md)。

## 启用前

1. 运维自行配置数据库、tenant、对象存储和HMAC密钥引用；不要把值交给模型、写进提案或报告。进程不自动加载`.env`。
2. 备份并核对当前checkout合法单一迁移head后按部署流程迁移。本批head为0046；历史免费发现报告的0040是当时状态，不是永久运行要求，旧部署未被本次测试升级。
3. API与scheduler分别显式配置`TRADEOS_QUOTATION_SETTINGS_JSON`。`infra/quotation_settings.py`校验core锁/语句超时、分页/到期批量，evidence原件/读取/解析/探测预算，以及可选files模板、页数/bytes/文本限制、读写预算、限流/Gateway lease。缺files不代表可生成文件；缺整项配置保留旧路径但报价能力不启用。
4. Linux受限parser在真实lifespan中probe；平台或能力不可用必须关闭，不使用宽松替身。API与worker分别管理独立实例。只启动API不会推进报价审批；同tenant scheduler须真实注册quote_approval、engine及outbox。
5. 用户明确填写利润底线/目标、22项费用归类、单价/整单精度、舍入方式、数量档、币种及有效期。同币种不填汇率；跨币种确认正向直连汇率与来源，不推断倒数。测试的50pieces、2USD采购、4USD报价、10%/20%不是生产默认。

## 业务顺序

- 已验证需求须有客户原话及完整Provenance，当前机会有有效负责人；研究Signal/Hypothesis不能直接当需求。
- 客户单位由有客户原件权的人逐字确认，产品员工不因成本角色获得客户邮件权。上传价格原件当前只允许其上传者读取，老板政策原件也须属于老板。
- 员工确认供应商针对规格、数量和有效期的quoted价格。22项成本逐一确认；不适用写理由，零金额写依据，缺失不当零。indicative只供内部估算，风险例外须独立审批留痕。
- 创建quoted成本版本，确认完整需求/条款/来源适用性，再由Decimal确定性计算报价；创建时冻结basis，不覆盖旧成本/报价。
- 起草人与负责人均不得自批，独立审批人核对精确变更；低价例外与承诺条款单独过门。批准不发送，PDF只含客户投影，不含内部成本、利润底线或供应商原话。
- 文件生成/下载独立ABAC，成本权不是文件权。quote ID深链核对精确版本；旧文件走历史授权，不能自动回退。

## 未知结果和停止

保存原幂等键、quote ID、工具调用ID，先只读核对记录；不要换键重试、清表、自动退款或重生成。
报价已写operation未记、审批效果已写mark_applied未记，依据原持久绑定恢复，不重新猜当前事实。
PDF已保存但关联未记，核对原generation call后人工metadata reconcile；不重写对象，关联成功不证明bytes可读或原工具调用成功。
未知对象写入不可盲重发；到期批次不把报价改sent。停止入口/worker后核实在途Run及账本，不删除不确定记录。

隔离测试栈自建PG，SDK受控、历史DNS/可达性/投递为模拟，无真实发送或供应商调用，不得连接生产库。
本机Docker internal网络原生发布未成功；测试专用loopback桥只经固定relay访问真实Uvicorn，不证明生产入口。
