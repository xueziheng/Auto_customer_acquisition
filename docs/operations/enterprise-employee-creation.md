# 企业管理员创建普通员工（2026-10-10）

按用户本轮要求，在老板已有服务器框架内补开户入口；不迁移旧本机配置。
ADR 0082 的四账号初始化保留作为历史基线，本入口不修改或覆盖这些账号。

企业管理员在团队页填写姓名、登录名、初始密码，创建本企业普通员工。
密码至少 10 字符；不允许指定其他企业、管理员角色或弱密码例外。

失败或结果未知时先刷新核对，不自动重试；同企业同登录名不能重复创建。

员工与登录账号同事务落库；使用原认证的强密码哈希、锁顺序、CSRF 和 no-store。
授权审计仅包含 actor/action/tenant/scope/rule，禁止记录密码及原始请求。
