# 低成本多来源公开检索

更新：2026-09-26。

目标是扩大候选覆盖：每个来源独立提供需求信号，不要求企业同时命中海关、官网、
社交平台等多个来源，也不要求先验证采购意向才留存。真实需求仍须客户表达；
搜索方向不能当作页面事实。

## 当前实现

内置会话的研究提案保留进口商、分销商、电商三类基础查询，再在老板明确的查询
预算内生成以下来源方向。一个国家/品类最多10条，适用的欧洲市场或英国增加
一条官方采购公告索引查询；这是上限内的有限模板，不会为凑足100次而重复查询。

| 来源方向 | 当前方式 | 不能据此声称 |
| --- | --- | --- |
| 官网与店铺 | 公开搜索及允许读取的网页 | 已有采购意向 |
| 行业企业名录 | 行业目录查询 | 企业已经工商核验 |
| 协会会员 | 会员目录查询 | 会员就是采购商 |
| 展会参展名单 | 参展名录查询 | 参展者就是买家 |
| 公开采购公告 | 招标、RFQ、适用国家公告网站的索引查询 | 已取得投标资格或客户回复 |
| 企业动态 | 扩张、新设施、采购招聘等公开线索 | 扩张必然带来订单 |
| 领英公开公司页面 | 公开搜索索引；页面允许读取时留证 | 开通了领英官方API或付费账号 |
| 公开贸易记录索引 | 公开运输/提单相关网页查询 | 接入了完整海关数据库 |

各方向先轮转搜索，方向内优先分配给搜索较少的国家/品类。每条查询先尝试一页，
再轮流读取第二页，避免第一个来源吞完页面预算。预算不足时不能保证全部来源
都执行；提案与运行摘要明确区分计划、成功搜索、已持久留证。

同一企业资料可从不同方向获得，保留各条来源归属；已有域服务继续按企业身份
去重。资料不全的页面可独立保存为待核验信号，第三方平台域名不作为客户官网。

## 费用与访问边界

- 搜索复用现有Tavily basic免费档门禁：账号用量不明、付费已开启、免费额度耗尽
  或请求结果不确定时停止，不回退付费来源，不自动重试不确定调用。
- 相同任务、租户、运行、员工和最终URL的成功页面，在Gateway每次重新检查后
  可复用本轮快照，最多50页。仍保留每次账本、页面尝试预算和一次性交付；
  缓存减少的是重复网络下载与原件写入，不是额外授权或无限页面额度。
- 登录墙、验证码、禁止访问和危险重定向跳过，不绕过限制；权限、政策拒绝仍关闭。
- 本轮不购买新数据库、不注册付费订阅。模型与基础设施费用独立于免费搜索额度。
- `research_only`仍只准备信号和假设，不会因增加来源而自动启动联系人补全或发送。

## 免费官方API的核验结果

已匿名实测[TED Search API](https://docs.ted.europa.eu/api/latest/search.html)和
[Find a Tender公共API](https://www.find-tender.service.gov.uk/apidocumentation/1.0/GET-ocdsReleasePackages)
能返回公告及采购单位数据。TED需要三位国家码；英国该接口按时间/阶段输出，
不提供全文关键词参数。两者不是通用企业或联系人数据库。

本机普通网页读取对TED公告得到202空正文，对英国公告得到403；结构化API可用
不等于现有HTML证据链已贯通。因此本轮没有把它们注册成已上线的数据连接器，
也没有把JSON伪装成网页原件。后续专用接入须保存真实API原件与字段来源。

当前本地环境检查未找到Tavily凭证引用或已确认专用账号配置，因此完整真实搜索
采集标记为`not_run`。受控Provider测试不能替代真实账号激活与数据质量验收。
