# ADR0106：QQ 回复候选查询兼容性

日期：2026-10-19。状态：隔离修复与验证，生产未发布。

真实 B 试验的原 Gateway 失败事件为 inbound.search / protocol:no，正文和模型调用均为0。
随后独立只读诊断在同一新UID范围9546:9546，确认原回复头+From+To组合返回NO，
UID范围+单一In-Reply-To返回OK且只有UID9546。地址组合查询返回NO，单独UID范围返回OK。
这是本次邮箱的实测结果，不推断所有QQ邮箱的协议能力。

将QQ初始查询改为UID固定窗口+单一In-Reply-To条件，不新增失败重试、ALL、历史扫描或宽泛备用查询。
服务器HEADER仍只是包含匹配；原本正文前的精确In-Reply-To、邮箱对、无抄送/附件、当前归属、
已发送Attempt及UIDVALIDITY核验全部保留。来自其他地址的同回复头候选最多读取最小头，不读取正文。
候选数上限、头/正文预算、受控窗口、模型配额和停止后的禁止重试保持原样。

原B停止记录、游标和模型0次事实保留，不自动重置或回放旧信作为新实时验收。
通过真实解析器+socketpair模拟观察到的组合NO，覆盖正确邮箱对通过、错误发件人/收件人不读取正文；
原搜索失败不回退、UID越界与授权撤销测试继续执行。合成测试通过不能替代新真实回信闭环。
