# 0089 平台模型 API 设置与既有凭证迁移

用户要求在平台管理添加模型 API 设置，支持 DeepSeek 和其他模型，并配置原有 DeepSeek 密钥。

平台管理员经独立会话与 CSRF 修改显式私有配置；响应不含密钥。更换服务商或入口不能沿用旧密钥。
服务商入口限定官方 HTTPS 地址，支持 Responses 与 Chat Completions，保留原 DeepSeek 协议。
每次修改创建独立配置版本与密钥文件；先保存，再经 model.connection.test 网关发一次短请求，最后显式启用。
网关测试具有租户/权限/一分钟幂等检查和持久审计；不在打开页面时调用模型。

systemd 固定部署服务消费启用请求，更新非秘密模型版本与企业配置头，重启已有单副本服务并核对心跳。
原 limits、研究开关、回复开关及数据外发许可保持原值；不新增模型路由、自动回退或客户发信权限。
已通过网关的精确租户/版本测试时间可作为既有模型就绪契约的部署验证；进程版本和心跳仍必须匹配。
后续企业显式测试失败会覆盖该验证结果。平台测试不等于业务能力评估，也不证明网页工具可用。

模型 Connector 在受信进程中解析版本化密钥；Codex 子进程仍只使用一次性 broker，不挂载凭证文件。
原 DeepSeek 密钥在服务器内迁移，不回传、不经模型上下文，不覆盖旧私有备份。

证据：DeepSeek 官方 Responses 接口 https://api-docs.deepseek.com/guides/responses_api/ 。
