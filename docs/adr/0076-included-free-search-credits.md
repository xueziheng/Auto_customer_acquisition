# ADR 0076：将套餐内免费额度与超额计费状态分开

- 状态：已接受
- 日期：2026-09-26
- 部分替代：ADR 0016 决策 4、5 中将未知按量状态等同于不存在可用免费额度的判断

## 背景与核实依据

真实 Tavily `/usage` 返回 `Researcher`、完整套餐用量、`paygo_usage=0`，但
`paygo_limit=null`。现有解码保留 `cost_status=unknown` 和 `paygo_enabled=None`
是正确的；将这两个字段直接解释为“套餐内免费额度也不可使用”则过于保守。

[官方定价](https://docs.tavily.com/documentation/api-credits)明确 Researcher 包含
每月免费 credits，PAYG 只在套餐额度耗尽后收费，basic 搜索每次消耗一个 credit。
[官方用量接口](https://docs.tavily.com/documentation/api-reference/endpoint/usage)
提供当前套餐名称和套餐用量。判断依据是精确套餐身份及实际余额，不是看到 1000 就猜免费。

## 决策

1. `SearchUsage` 增加默认 `False` 的严格布尔字段 `included_credits_free`，表达
   **套餐内 credits 的免费性质**，不表达超额计费开关、未来周期额度或账户永远免费。
2. Tavily 仅在精确 `Researcher`、`plan_limit`/`plan_usage` 均为合法非负整数、
   `paygo_usage` 明确为整数零，且 `paygo_limit` 字段存在并为整数零或显式 null 时
   产生此事实。字段缺失、错误类型、未知套餐和明确付费状态仍不具备资格。
3. `cost_status` 和 `paygo_enabled` 保留现有原始判断；null 不改成零或 False，
   不伪造账期。新事实不能与付费套餐、未知套餐、缺失余额、明确启用按量状态并存。
4. 免费门禁仍先拒绝 `PAID` 或 `paygo_enabled=True`。其余情况只接受旧的明确免费
   证明或新的套餐内免费证明，随后按实际余额预留一个 basic credit；余额耗尽停止。
5. 新事实与用量快照在现有账户行锁事务中持久化。新增数据库列默认 False，历史记录
   不自动回填；用量读取失败清除该事实。研究页面可以显示最近核验的套餐内免费余额，
   但 GET 不访问供应商，历史快照不能代替每次调用前的新鲜 `/usage`。
6. 保留账户级独占配置、租户绑定、单数据库持久额度槽、累计 reservation、
   ceiling 只降不升和不确定结果不重试。不同 key 不能成为重置账户额度的手段。
   不根据本机月份刷新、不退还不确定额度、不自动启用付费和备用收费供应商。
7. Sourcing 现有更严格的未知状态拦截保持原样，本次只修复公开研究的免费套餐路径。
   不修改根目录九条硬边界、Gateway 核心管线或发信审批。

## 成本边界与限制

供应商用量可能延迟，因此仍累计扣除 reserved、uncertain、consumed，不因新快照未增长
而返还。跨月额度增加也不会自动扩充本机 ceiling；保守重复扣减可能少用免费额度。

账户在另一客户端、其他 key 或另一套数据库中同时消费，无法仅靠本机事务锁保证余额。
因此独占要求是账户级要求，不能用“单个 key 已限额”替代；非独占部署不应启用本路径。
供应商套餐或接口语义改变时仍须重新核实，不猜套餐别名或 null 的按量开关含义。

## 验收要求

- 有效 Researcher/null 响应保留 UNKNOWN/None，同时具有套餐内免费资格。
- 缺字段、布尔冒充整数、错误类型、未知或付费套餐、明确 PAYG 均不放行。
- 最后一个免费 credit 被并发请求竞争时最多一次派发；耗尽、崩溃和旧预留不重发。
- 历史数据库迁移默认 False；新鲜核验后持久 True；核验失败回到 False。
- 真实验收只用隔离测试库；先核对历史真实搜索零派发，每个验收阶段最多两次 basic。
  首轮已成功派发两次，但两条首选页面均被访问策略拒绝，未形成信号。修复同批页面
  回退后，追加一次两次搜索的免费复测，整个验收累计硬上限为四次。复测须恢复原库
  和原计数文件，保留旧预留与回执；人工测试上限由 2 调到 4 单独留痕，不改生产
  ceiling 只收紧的算法、不伪造供应商余额。所有真实请求经过 Gateway，不能把受控结果当 live。
- 从正常 TradeOS 页面确认研究，核对真实返回页面、原件引用、运行记录与额度变化。
  本次免费测试不调用付费模型、联系人服务或邮件；本地确定性提取不冒充模型验收。
