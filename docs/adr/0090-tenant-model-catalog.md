# 0090 多模型配置与公司固定选择

用户于 2026-10-12 明确要求平台保存多组模型连接，按公司选择，Agent 继续使用 Codex CLI。本次是管理员固定选择，不按价格自动路由或回退，不改九条硬边界。

模型连接与运行策略分离：原 configuration_version 继续约束权限、资料外发与限额；新增连接版本随 tenant + run 持久绑定。任务首次调用记录不可变连接快照，后续调用与重启恢复沿用它。新任务读取公司当前选择。切换模型不修改共享 Codex HOME，不重启其他公司的任务。

平台控制租户持有连接库与私有密钥，公司只持有授权引用。企业身份由部署和任务身份交叉校验。业务调用先重核原权限，再绑定连接；未知企业不继承 JSLT 配置。密钥由受信 Connector 读取，Codex 子进程只持有本任务桥接地址。

连接库列表展示名称、模型、接口、API 测试、Agent 测试及使用公司。编辑保存创建新版本，不自动切换已绑定公司。公司选择通过测试的确切版本；被公司使用的配置不能删除。原 DeepSeek 配置迁移为一张卡片并保留 JSLT 绑定。

Codex 工具能力必须单独验收。API 连接成功不作为完整 Agent 可用结论。多轮桥接限轮数、输入、输出和总时间，保留无自动重发。先提供任务上下文只读 MCP；业务搜索、网页和外发继续经过其既有 Gateway，不因切换模型额外授予权限。

## 运行边界与成本

模型任务在第一次获准进入模型 Gateway 时持久绑定版本；后续轮次和重启恢复沿用该版本。尚未调用模型的业务流程不提前占用模型配置。
每次逻辑生成最多四次 Provider 往返，共享原有输出 token 上限和总执行超时，输入重放会增加用量。账本累计实际 token；任一轮缺失计量时保留未知且不继续扩张预算。
首批 MCP 只提供本次获准任务的上下文读取。外部搜索、页面、浏览器和发送仍使用现有的独立 Gateway，不因更换模型开放额外权限。
当前独立部署配置固定一个企业运行时；目录中的其他企业可保存模型绑定，但必须具备该企业自己的 API/worker 配置和权限才能执行，不回退使用 JSLT 的运行身份。
