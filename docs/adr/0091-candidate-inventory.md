# ADR 0091：公共候选库存与独立企业交付

状态：用户批准（2026-10-13）。

公共企业事实由受信采集链生成，平台公共仓储绑定 control_tenant。只有登记且进入显式公共来源白名单的网页/API证据（含需要key的SAM.gov公开采购API；认证方式不代表数据私有）进入白名单模型；必须有 URL、原件 ID、内容哈希、提取者与时间，禁止上传、会话、推断和任意扩展字段。模型校验是数据准入边界，不是网页真实性证明；采集器需核验原件。本次不实现外部采集。

公司服务绑定 business_tenant，公共读取用独立控制面会话，之后在公司事务内锁额度行完成独立分配、请求幂等与缺口排队。每企业域名和邮箱唯一；不同企业可分别得到同一公共企业。投影不包括其他企业业务数据。固定数据库角色 RLS 保持强制 tenant 隔离。

日额度默认50，每次最多100，以公司显式时区（默认Asia/Shanghai）确定交付日。只在交付时计费，排队不预扣；并发统一锁公司额度行，worker交付也遵守同一锁与当天额度。期限已过的候选不得交付。零额度请求可排队，等待未来额度。

任务租约带每次领取更新的令牌，旧worker不能保存尝试或完成交付；过期可重新领取。公开结果先保存平台库存，再在公司事务内交付；这两个数据库边界不能宣称单事务，崩溃重试通过候选去重和请求/任务幂等恢复。

来源选择只用真实运行状态，静态selected不代表可用。来源预算是调用槽位数，不编造货币成本；用已核实成本类别、相关性、历史收益排序，并保留至少一个按最少尝试/最久未用轮换的探索槽位。计划执行者必须完成预定探索槽位，不因首源命中短路。
