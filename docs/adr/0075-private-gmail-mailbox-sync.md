# ADR 0075：本人 Gmail 全量邮件镜像

日期：2026-09-22。需求：操作者要求在项目内看到本人邮箱下所有邮件，含历史聊单。

## 决定

在 Conversations 内增加独立的本人邮箱镜像，复用现有 PostgreSQL、认证、Tool Gateway 与 Web。
镜像不要求 ProspectAccount、Campaign 或系统外发事实，也不生成客户、已验证需求、报价或发送事件。
旧 30 天入站/反馈关联通道保持原语义；全量镜像是用户明确要求的新读取用途。

租户、当前 active 员工、绑定时的登录 user_id 和不可变邮箱 owner 同时限制读取；老板与经理没有越过本人范围的特权。
账号以 Gmail profile 核验，OAuth 只申请 gmail.readonly；凭证仅在 connector 内部私有文件中解析。
产品不能复用 Codex 的 Gmail 令牌。只读 OAuth 授权由本机应用向导完成，邮件收取和增量刷新经新增具名 Gateway 工具，核心管线不变。

首次固定 history 锚点后逐页补录所有邮件（含 SENT、归档、DRAFT、SPAM、TRASH）；之后按 history
同步新增、标签变更及删除。404 历史过期触发完整重扫，只有成功扫完才清理镜像中已不存在的记录。
每页消息、删除与 cursor 在同一事务提交；账号 revision CAS 和数据库 advisory lock 防止乱序覆盖。
失败保留检查点并显示固定原因；没有全量结束和 history 追平不能声称同步完成。

邮件正文仅供本人页面查看，显示为纯文本，不加载原 HTML、脚本或远程图片。保留 provider 原始响应、
原始消息 ID、线程 ID 和时间作为来源；附件显示名称/大小，原件通过 Gmail 打开，不伪称已下载。
邮件镜像不进入 Agent 上下文、工具 ledger、日志或公共仓库。普通邮件不能冒充业务证据。

## 运行与验收

本机邮箱同步作为现有 email_feedback_worker 的独立只读入口，不启动旧反馈或发信流程。
操作者提供已授权的私有 Gmail 配置、真实 profile 和本人员工账号。后台可独立于 Codex 运行。
验证全量分页、锚点追平、去重、事务回滚、跨租户/跨员工拒绝、撤权、中断恢复、过期重扫、
迁移往返，以及 Web 搜索/筛选/长会话分页与身份切换清理。
