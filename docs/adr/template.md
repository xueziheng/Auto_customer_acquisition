# ADR NNNN：标题

- **状态**：提议 / 已接受 / 已废弃 / 被 ADR-NNNN 取代
- **日期**：YYYY-MM-DD

## 背景

要解决什么问题？当时有哪些约束（时间、人力、数据、法律）？不写背景的 ADR，半年后没人看得懂为什么这样选。

## 决策

一句话说清选了什么。

## 理由

为什么这个选项胜出。**重点写取舍，不是优点列表**——只列优点等于没有论证。

## 放弃的选项

每个被放弃的选项写明：它好在哪里、为什么现在不选、什么条件下会重新考虑。

## 后果

接受了哪些代价？埋了哪些技术债？谁在什么时候要还？

## 何时重新审视

写明触发条件（数据量、团队规模、具体痛点出现），而不是「以后再看」。
