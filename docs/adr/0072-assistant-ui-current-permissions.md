# ADR 0072：助手操作入口与当前权限投影

日期：2026-09-22。状态：采纳。

## 问题

助手对 cancelled/blocked 轮次显示后端禁止的重新生成按钮，并向所有角色显示老板专属的运行审计入口。
模型设置在编辑期间刷新配置版本，却保留旧表单，保存时可能用新版本覆盖其他管理员的更新。

## 决定

TurnView 增加缺省为 false 的 `can_view_run` 安全投影。HistoryProjector 根据本次解析的当前角色、
内容可见性生成；来源撤权时为 false。它只控制界面入口，运行审计 API 原有当前身份检查保持不变。
无字段的旧响应按不可见处理，不把保存的历史角色当作当前权限。

重新生成入口只对应域现有 failed/unknown 规则，不放宽后端状态机。
模型表单固定开始编辑时的 expected_version。读到其他版本后保留草稿但禁止保存，
由用户明确放弃修改并载入当前配置；并发保存仍由后端 expected_version 检查兜底。

## 代价与验证

新增响应字段需重新生成前端类型，无数据迁移。保守隐藏可能短暂延后可用入口，避免提供确定失败的操作。
角色变化/来源隐藏、终态按钮、并发编辑均先补失败用例，再验证修复。
