# ADR 0085：平台获客来源目录与只写凭证管理

状态：按用户 2026-10-11 明确要求实施。

## 决策

独立平台后台集中展示所选、备用和示例来源，按企业数据库、联系人、采购、贸易记录及行业网络分组。
用户要求平台管理员添加、修改、删除 API 密钥；复用 ADR 0082 当前平台授权，不硬编码账户名称，
不向普通企业 API、模型上下文或工具参数开放凭证读取。

来源静态目录在 shared，只含网站、访问方式、凭证字段名称和实现状态。组织域管理安全投影与授权。
HTTP 输入为只写 SecretStr，手动限制请求体并返回固定错误，避免 FastAPI 原始 422 包含输入。
GET 永不返回密钥、引用、哈希；配置状态、接口实现状态与实测状态分别表达。

部署显式传入 profile/data-sources，独立文件由服务运行用户持有，目录 0700、文件 0600，
拒绝软链接、多硬链接与不安全权限。操作持锁，凭证、版本及安全审计一次原子替换；不修改原 profile secrets。
每次写入或删除带 expected_revision，生成新版本并清空旧测试。删除保留版本墓碑及不含凭证的审计，
不保留旧值；不等于撤销供应商网站上的密钥。配置、审计与受信读取均绑定独立控制租户。

保存不会访问供应商、注册运行时工具或启用自动触达。测试结果只能由受信 Gateway 实测写入，
必须匹配精确版本；Hunter 现有业务 readiness 与本管理状态相互独立，不能用“已保存”替代业务准入。
平台密钥只供显式受信连接器组合读取，不授予企业跨租户读取或共享业务数据的权限。

## 验证与限制

覆盖授权与 CSRF、只写响应、异常脱敏、私有权限、完整字段、并发冲突、跨租户拒绝、轮换和删除失效测试。
存储使用权限隔离而非加密磁盘；备份必须保持相同私密约束。来源目录中待接入项仍不能采集，
运行时采用新密钥需显式完成连接器装配与既有门禁。真实外部测试单独记录，不由合成测试推断。
