# ADR 0073：模型选择来源，代码生成解释正文和引用

日期：2026-09-22。状态：采纳。

## 问题与证据边界

真实 DeepSeek 测试发生过模型请求成功而会话失败。首次被拒绝响应未保存，不能确定该次具体原因。
检查发现旧输出协议要求模型逐字复制原文并填写来源身份；离线测试可确定性复现：即使引用存在，
改写正文也会被摘录护栏拒绝。不能为提高成功率放宽无证据断言检查，也不能自动重试付费请求。

## 决定

`assistant-v2` 的模型侧 `explain` 只包含本次 `untrusted_sources` 的零起始 `source_indexes`。
代码验证整数、去重和越界后，从当前授权上下文取完整来源原文生成领域 `Explanation`。
模型不再生成解释正文、来源 ID 或历史轮次 ID；历史 result 明确不是本轮输出模板。

生成的领域结果继续经过凭证/商业承诺护栏、完整依赖闭包、交付前来源重核和历史撤权投影。
`clarify/read/research` 语义不变，不增加调用次数或自动重试。未知下标与额外自由正文拒绝。
Web/领域 DTO、数据库结构不变；旧已持久化 Explanation 可继续读取和应用。
部署时 API 与 scheduler 使用同一构建，避免滚动期间不同提示协议混用；历史成功会话不重新生成。

## 诊断与代价

校验错误提供固定 `output_schema/output_reference/output_excerpt/output_guardrail` 分类，
写入 Workflow context 的 `assistant_output_failure` 白名单字段；引擎的通用失败摘要仍脱敏。
会话仍返回兼容的 `invalid_response`。不保存失败响应原文或校验输入。
这是审计分类，不扩大模型权限。

完整来源可能比模型摘录长；本轮优先保证事实可追溯，不允许借简写加入无证据结论。
当前资料整体命中其他既有护栏时仍会拒绝。真实模型可能输出错误下标或其他非法 JSON，
因此本决策消除的是“模型抄错正文/引用导致失败”，不承诺任意模型结果都能接受。

验收要求：模型协议与旧持久化协议分离、来源范围/闭包与撤权、同一消息不重复调用、
多轮真实 PG 回归、评估集和有限真实模型复验。首次未留存响应的根因仍按未知记录。
