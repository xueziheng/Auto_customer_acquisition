# ADR 0088：获客来源按接入方式显示状态

状态：接受，2026-10-11。用户明确要求 API 显示额度、登录网站显示登录有效性、公开网站显示可访问性。

新增无凭证 BrowserProbeObservation 公共契约，主 API 经独立 Gateway 插件调用部署绑定的 UNGM 试验服务。该服务是已有隔离浏览器适配设施，固定 loopback 地址；不开放任意 URL、账号或 Cookie 输入输出，不作为通用 API/worker 相互调用机制。其浏览器仍独立容器运行。

平台管理员权限与 CSRF 沿用现有入口，检查经过 tenant、permission、idempotency、rate_limit 和持久审计。保存独立的控制租户检查快照，页面刷新只读取快照。每分钟最多一次检查；成功超过一天显示待复测，而非断言会话过期。403、超时、无有效登录标志均不能伪报登录过期。只有明确回到登录页才显示需要重新登录。

UNGM 测试只重开专用服务器浏览器并恢复目标网站会话，检查账户页，不调用 API、不读取采购附件、不执行发信。仅部署显式启用时提供测试按钮。API 状态保持原语义，公开网页未接入检测时明确显示尚未测试。登录有效不代表正式业务采集或供应商资质已就绪。

凭证继续保存在浏览器容器的独立私有目录。平台只能得到固定分类和时间，不取得 Cookie、Local Storage、账号正文或页面内容。不改变九条全局硬边界与 Gateway 核心管线。
