# ADR 0071：会话机械装配与模型探测生命周期

状态：实施。日期：2026-09-22。

## 决策

允许 apps/composition_support/assistant.py 机械构造本进程独有的会话、配置仓储和公开事实读适配。
权限规则仍在领域服务和 agent_runtime 的具名适配中；不得导入 API 或 scheduler 进程，
不得建 engine、启动后台调度或读环境。model.py 仍只装配模型 Gateway。
API 与 scheduler 显式传入自己的 session factory、服务、配置、时钟和 HMAC provider。

模型调用仍只有 scheduler 持久流程；API 心跳仅表示自身装配版本。scheduler 只有取得
原单副本锁后才注册装配状态，扫描前刷新心跳，退出移除自己的实例记录。
管理员探测是固定无业务正文的 model_probe 轮次，使用同一 Gateway 和配额；
版本改变、取消或当前员工撤权后的迟到结果不得将新配置标为已验证。

探测完成在会话与员工行锁下重核领域授权，再原子记录完成与验证时间。
新配置只增版本；修改后要求两个进程以相同版本重启。未配置搜索不会阻止产品帮助或提案准备。

独立模式可显式提供 research_factory，与旧静态研究端口互斥。只有同时存在会话工厂、
研究工厂和独立研究标记时，本机资源配置才允许 research_only；旧 pilot 默认继续禁止。
模型身份由规范 Run 的提案主键、正式确认人和当前员工映射重建，不接受 context 里的身份。
研究仍沿 v2 execute_search（既有 max_retries=0），模型未知结果终止该 Run 并保留额度。
可选研究配置只在部署文件给出，不自动启用搜索，Tavily 账户必须显式确认独占并通过免费额度检查。

## 整分支审查后的补充约束

- 会话恢复读取网关不可变调用账本中已绑定的配置版本，而不是用重启时的新版本推测旧结果。
  任何已存在版本与本进程不一致都阻断；每个业务步骤（包括检查点恢复后的应用）重新检查当前配置。
  不另建第二份可漂移的配置绑定表；配置检查失败不改写已发生的用量。
- scheduler 模型心跳在规范单副本激活后启动，独立于业务批次耗时；每次写心跳前核验同一锁连接，
  与主循环的锁检查串行化。释放锁前先停止心跳，资源退出再次幂等关闭。心跳不执行恢复扫描；
  恢复仍只发生在原持锁 driver，不能在并行心跳中修改在途请求。
- 管理员可经带 `expected_version` 的非秘密设置接口修改业务资料外发许可；保存创建带操作者与
  时间的新不可变版本。修改后仍需同步部署文件、重启与显式探测，不靠直接改表激活。
- 会话来源集合统一限制为 256 个，模型调用前检查，再由仓储核对相同上限。单次业务列表仍最多 50 条。
  该限制保护历史来源闭包，不表示可以绕过每个对象的当前权限或输入字节额度。
- 共享研究提案只投影已校验的研究字段与来源标识；完整聊天不复制到 DirectiveProposal.raw_text。
  仍以私有轮次和规范提案的来源关联约束保证幂等，不新增聊天审批或业务执行权限。
