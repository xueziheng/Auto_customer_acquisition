# ADR 0087：可编辑的来源备注

2026-10-11，状态：已采纳。

平台管理员需要自行维护来源的费用、开通进度与使用限制。账号注册和观察到的价格属于人工记录，
不得写入全局静态来源定义，也不能据此改变系统的密钥、测试、额度或采集接入状态。

- 所有已登记来源均可编辑普通文本备注，最多 2000 字；空文本保存即清空。
- 复用独立平台授权与 CSRF，所有读写绑定控制租户。备注独立版本校验，旧版本返回冲突。
- 私有目录 `notes.json` 原子持久化，锁内更新，文件 0600；与凭证配置分开。记录修改人、时间和
  操作元数据，清空后保留版本墓碑。审计不另存备注历史正文。
- UI 以“管理员备注”展示、按普通文本转义，提供添加/编辑、保存、取消、清空内容。
  备注可以搜索；编辑期间暂停本页自动额度检查，切换身份清空草稿并忽略旧响应。
- HTTP 错误不回显请求或底层异常。冲突和不确定结果保留草稿，要求刷新核对。
- 此入口不调用第三方接口、不启用采集，也不配置网站会话。费用说明由管理员编辑后保存，
  不内置某个账号或网站的当前套餐价格。
