# ADR0110：已验收私有 QQ 会话持续收信

2026-10-20 用户按老板第三项要求明确启用服务器新版本的日常持续收信。

持续配置与限时试验、仅恢复模式互斥。持续配置绑定已停止试验的原路由、唯一成功
Attempt、原有别名采集证据与授权引用，不延长或重置旧试验。原 cursor 原位保留，
首次无游标必须失败；仅操作者核对旧到期阻断后可按原版本调用 retry，绝不跳水位。
新信、迟到回复与重启后的分页都沿原 singleton、Gateway 与整页事务。

别名每页重查当前员工、本人邮箱、私有用途、同意、归属和真实已发送事实，以及
原成功采集工具账本和原件摘要。只读取原两个邮箱之间对指定邮件的精确回复。
复用已验收的 QQ 地址及 MIME 检查；不扩展普通客户、其他邮箱或自动发送。

每次正常扫描间隔至少 60 秒，时间由数据库 last_succeeded_at 保留，重启不能重置。
暂态失败按原持久 next_retry_at 恢复；认证、UIDVALIDITY 或关联异常保留阻断，
不跳过候选、不抹除失败、不重新扫描历史。整页 cursor/receipt/Message/outbox
原子提交；分类和通知沿原持久幂等身份。暂停 Campaign 不停止既有回信接收。

模型仍经现有按公司配置、当前资格与 model.generate 账本及每日额度。
持续路径采用相同已验收回复专用指令，单任务使用原 AgentBroker 的四轮、
累计 512 token 输出与原时间上限，未知结果不自动重发；不提高既有每日 3 次配额。
额度耗尽不等于漏收，消息保留，分类失败仍按原恢复流程处理。

本次无共享事件或数据库 schema 变更。验证包含新信/迟到、分页、进程重建、
重复页、UIDVALIDITY 变更、权限撤回、别名缺失、正常轮询冷却及事务回滚。
真实服务器验收必须单独记录，fixture 不代表真实持续运行已经验收。
