# ADR 0114：企业确认资料作为私有客户搜索上下文

日期：2026-10-21。状态：已采纳。

## 背景

原 InventoryQuery 只承载公开产品标签及单一国家/非洲范围。直接将企业自然语言要求、资料引用或原文传入公共目录或搜索引擎，会跨越企业资料边界。资料库的人工确认也没有正式 Product 发布、Campaign 批准或对外商业承诺的语义。

## 决策

- 在兼容旧 region/country/product_tags 的企业任务 JSON 上增加 intent、regions/countries、confirmed_refs。新字段参与幂等指纹，默认空字段不改变历史请求指纹；不新增知识库或数据库表。
- confirmed_refs 精确绑定 document_id/revision_id，最多5份。应用/工作流的 ConfirmedContextReader 只通过 Products 公共 EnterpriseKnowledgeService.get_detail 读取当前员工、当前企业、当前人工确认版本。完整保留事实、推断和 Provenance，整体上限60000字符，超限拒绝；不扫描 vault、不缓存原文。
- HTTP 提交前验证引用。实际 InventoryDiscoveryModel 将授权上下文放入内部模型请求；每次模型授权检查和调用后重核引用。采集工具循环与 Gateway 的 guard 在每次外部工具调用前重核员工、租约及资料，因此执行中撤权会停止下一次派发。
- 公共目录边界必须调用 public_projection，只含用户显式公开产品检索锚点及地域；不包含 intent 或 refs。原有候选 Provenance 仍仅来自真实公开页面。
- 私有上下文存在时，搜索补充词使用代码白名单：用户公开产品锚点、受信来源策略/通用商业角色词及本轮已观察公开域名。模型不能将任意资料词拼入外部查询。已观察域名作为完整词保留，使目录→企业官网的跟进可继续。
- 多地区是并集，国家进一步收窄；矛盾国家/地区提交失败。新地区/多国家查询允许模型用选定范围内的公开国家名称细化，未指定时按固定国家集合轮转，每次搜索和其页面批次共享同一 Gateway country preflight。搜索预算仍有上限，选择一个大区不承诺穷尽所有国家。旧单地区查询保持原执行方式。
- 复用原搜索表单和企业资料库列表，选择已确认版本。最多100份当前列表中的确认资料可供选择，默认选前5份；无确认资料或未选择时明确按公开关键词搜索，旧API无引用路径继续执行。提交和恢复只保存引用及要求，不保存知识原文。换账号清空并拒绝迟到响应。
- 国家名称证据表补入 IANA tzdata iso3166.tab 的公开英文名称（本机文件标注2025-07-01、public domain），保留既有名称拼写。仍必须从公开页面的明确经营地址证明国家；名称映射不是位置证据。

## 后果与限制

确认资料仅用于内部匹配，不能推导客户采购意愿、正式产品或触达授权。外部产品锚点应由用户明确填写；自然语言目标可指导模型选页及筛选，但不能授权外发内部资料词。历史资料仍通过原上传、处理、人工确认入口进入本企业资料库，Obsidian 原件和版本投影不变。

地区数据用于公开搜索范围，不授予发信或国家合规许可。公开邮箱仍未验证；后续沟通必须沿既有验证与逐次商业审批边界。验证仅使用合成资料、受控模型和本机 PostgreSQL，没有生产模型、真实搜索或邮箱调用。
