# 按公司配置模型实施计划

用户已确认“模型库 + 公司选择 + Codex 执行链”，实现与部署由本任务继续，保留已有凭证和运行策略。

1. 在组织域增加模型卡片、公司绑定和测试状态契约；私有存储实现多配置、不可变连接版本与按任务绑定。验证跨企业拒绝、切换不改变在途任务、并发版本冲突、删除保护、密钥不进入投影。
2. 增加平台授权 API：列表、新增/编辑/删除、API 测试、Agent 测试、公司绑定；身份与公司目录双校验。沿用 CSRF 和 Gateway 审计。
3. 增加受限 Codex 多轮桥接和上下文 MCP；官方 Responses 与 Chat Completions 适配。验证真实工具调用、隔离、取消清理、请求/轮数限制；失败不得冒充可用。
4. 运行时按可信 tenant/run 加载固定连接，保留原配置权限与限额；资料、助手、研究、回复的模型步骤使用 Codex 执行适配。
5. 前端展示卡片列表和编辑详情；公司选择框显示当前模型、明确保存/测试/绑定反馈；类型由 OpenAPI 生成。
6. 合成两企业隔离回归、前端构建与结构检查；在服务器备份后迁移已有 DeepSeek/JSLT，并进行小额真实 API 与 Agent 验收；失败则保留旧生效配置。

审查重点：公司 A 不读取 B 的运行绑定；更换地址不沿用密钥；绑定版本与测试版本一致；未知调用结果不重发；测试不能更改公司选择。
