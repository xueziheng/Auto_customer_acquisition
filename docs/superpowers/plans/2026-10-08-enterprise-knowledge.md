# 企业资料库实施计划

依据 ADR0083 与同日设计；目标是把既有隔离基座接成真实网页上传→Codex/DeepSeek→企业vault。

1. 领域契约与数据层：企业资料、任务、版本、当前员工授权、上传幂等、lease/fencing、
   人工确认、人工重试、独立投影状态；0072迁移及强制RLS。
2. Codex连接器：每任务快照、bwrap、临时会话、无凭证CLI、Unix broker、
   至多一次DeepSeek调用、最终JSON绑定；真实CLI离线探测与异常/取消测试。
3. 原件与解析：TEXT契约，严格类型/文件名/体积，受限PDF/Office/CSV/文本解析，
   来源文本与凭证输入护栏；有界图片/扫描PDF真实视觉输入与页码；模型逐字引文/推断结构评估。
4. 流程与投影：singleton下单任务处理，重核授权，Gateway现有配额账本；
   确定性租户vault写入、版本保护、失败恢复，不给模型生产文件写权限。
5. 网页与API：共享资料列表、上传、真实状态、原件下载、详情、确认、
   显式重试/同步；同源CSRF、生成API类型、身份变化清空旧数据。
6. 验证：轻量定向测试、结构边界、敏感扫描、CI全门禁、
   真实PostgreSQL跨企业与迁移往返、真实CLI离线隔离、
   合成文档线上完整链路及一次服务重启。
7. 提交/push、检查精确SHA CI、发布、交付网址与使用步骤；删除本次临时测试资源。

记录必须区分离线替身测试、真实CLI、真实DeepSeek与线上事实；没有执行的步骤不标通过。
