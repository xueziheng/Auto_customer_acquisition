# 旧测试请求续办与排队期限纠正

用户已批准 C 零派发请求一次续办，随后明确几分钟期限仅限助手测试。普通用户不得承担测试倒计时。本计划只纠正误入通用代码的期限，保留旧测试证据并完成 C 的真实 UI 验收；不新增独立验收页面。

1. 0082 允许未来恢复请求 expires_at 为空，旧值不可改。旧测试请求可追加最多一条不可变续办凭据，不增加模型次数，不重置预算；旧 QQ trial 不启用。
2. 续办严格检查原操作者、当前权限/关联/配置/额度、零开始/零派发/无分类/无 seq1，恢复已有规范 Run 与 pending classify 步骤。普通无期限请求永远没有续办入口。执行前仍重核事实，实际模型60秒超时保留。
3. HTTP 空命令、原 key、UI 显式一次操作；刷新只读、未知不重发。旧过期事实和原失败不覆盖。
4. PG 迁移往返、并发/不可变性/权限、真实引擎 poll_due 驱动真实 Gateway 分类事务、UI 及类型检查；一次最终独立审阅。
5. 仅隔离实例备份、0082迁移、新表租户角色授权、重启健康核验，UI继续 C 并核对真实模型/工作项/通知。购买意向与长期收信另列未完成。
