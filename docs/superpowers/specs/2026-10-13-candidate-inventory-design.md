# 公共候选库、按公司交付与有界采集设计

用户已经批准本设计方向并要求直接实现、部署后使用 jslt 进行 UI 验证。本文记录执行规格，不另设泛化审批步骤。

## 目标
将一次性搜索转为可复用的公开候选资产。企业按日取得新候选，同公司所有员工共享去重与额度，不同公司独立分配。来源调度使用真实可用状态与历史增量收益，同时保留轮换探索预算。Codex CLI 通过受限工具参与检索、浏览和提取。

## 边界
公共候选不是已验证需求，也不是可直接发送联系人。原始公开来源与提取事实可复用；员工上传、邮件往来、归属、商业判断、报价只留在公司内。公共目录归属控制租户，所有 SQL 都有 tenant_id；业务租户通过受信公开投影服务取得允许字段，不可查询其他公司数据。

每家公司新的分配按规范化企业域名去重，邮箱另设唯一分配键，跨查询和跨员工生效。并发领取、重试、额度消费在同一数据库事务内；幂等重放返回原分配且不重复扣额度。原持有人可查看历史；经理和老板按已有权限查看。其他公司从公开池独立取得同一候选。

首版配置日额度（默认 50，可由平台管理员修改），每次最多领取 100。采集批次与交付额度分离；可申请补充至 50/100 条候选库存。库存命中先交付，不足创建持久任务。数据必须包含来源 URL、source_id、观察时间和事实片段；邮箱始终先标记未验证。库存过期不作为新交付，旧分配仍可见但显示过期。

来源注册表读取现有 33 个 selected 来源。每个来源分别呈现 API、公开网页或浏览器采集方式和真实可用性；无权限、缺配置、未实现、临时失败明确区分。不得把来源注册或网页能打开伪称为联系人链路已完成。每批只跑有界来源与请求，保留至少一个可用且未充分探索的来源名额；按唯一有效新增与覆盖调整优先级，固定来源不会永远霸占前列。结果不确定的付费调用不自动重试。

Codex 子进程不持有凭证、数据库或任意网络。搜索、读页、浏览器工具由父进程经 Tool Gateway 执行，严格预算、域名/SSRF 校验、来源证据回传；模型只建议与提取，代码决定预算、来源可用性、去重、落库和额度。API 连接器由代码执行。浏览器抓取限制公开页面，不处理支付、客户发送或绕过登录验证。

## UI 验收
jslt 登录后可提交非洲三轮车等查询、看到库存/任务进度/来源状态、领取少量结果、查看证据与未验证邮箱；再次领取不重复、重新登录仍存在。模拟第二员工与第二企业的授权集成测试验证并发和隔离，不在生产伪造身份。真实邮件测试仅限已授权测试收件人；缺少条件时明确记为未验证。
