# Phase 2 首批：免费来源获客（已确认规格）

本规格转录用户确认的实施边界，不新增 Phase，不替代 HANDBOOK。Phase 2 为「获客能力增强 + 寻源、成本与报价自动化」；本批交付获客增强，原有寻源、成本、报价保留在后续交付中。

## 发现线路

老板指定国家、品类、排除项与预算，确认提案后执行三类查询：

| discovery_lane | 来源 | 证据边界 |
|---|---|---|
| importer | 官网、公开行业目录、贸易网页 | 无运输记录证据只能是进口商候选 |
| distributor | 公开渠道目录、品牌经销商页面、官网 | 核实业务与地区，不推定采购需求 |
| ecommerce | 公开店铺、商品、品牌及联系页面 | 技术特征仅辅助，不证明 OEM 需求 |

线路描述检索来源，不是已核实企业身份。跨线路、跨国家命中同一企业使用已有域名消歧与账户规则，多份证据保留。缺少可核实官网或国家的结果保持待核验，不创建合格候选。搜索国家偏好不是企业所在地证据。

## 搜索、额度与扩展

- Tavily 免费档：固定 `basic`、`auto_parameters=false`、不生成答案、不启用额外付费能力；搜索结果仅定位原网页，证据来自现有安全页面读取器和不可变快照。
- 搜索前读取 `/usage`，确认免费计划、剩余额度、按量计费关闭；任何状态未知、付费开启或额度不足均阻断，不升级、不回退付费来源。
- 持久化账户绑定、额度预留及消耗，同一绑定账户跨 Run 统一计算；不确定结果保留预留且不自动重试。每轮查询/页面上限仍有效。
- 连接器边界提供供应商无关的搜索结果、能力及额度查询 Protocol，Tavily 实现；既有 Brave 兼容。
- 不实现商业数据商专属客户端，未实现服务不注册可用工具。预留接口不意味着只填密钥即可使用。
- 不修改 Tool Gateway 核心检查管线，不建设积分钱包、自动采购或全网爬虫。

官方规则随启用时复核，不将 1,000 credits/月硬编码成永久承诺。依据：[API credits](https://docs.tavily.com/documentation/api-credits)、[Usage](https://docs.tavily.com/documentation/api-reference/endpoint/usage)、[Search](https://docs.tavily.com/documentation/api-reference/endpoint/search)。未知免费计划标识、未知重置周期必须保守拒绝或保留预留，不能猜测清零。

## 流程与公共契约

老板指令 → 确认提案 → 三类检索 → 原网页取证 → 企业核验/去重 → Demand Signal → Need Hypothesis。

- 新模式 `research_only` 不要求 Campaign，不启动联系人补全、邮箱验证、邮件发送或报价。
- 旧触达准备模式保持原解释；历史无线路查询不自动改成新模式。新查询明确 `discovery_lane`，通过版本化工作流隔离语义。
- 来源 URL、观察时间、哈希、快照及字段级 Provenance 沿用现有链路；目录描述、企业自述、模型推断分离；网页指令不作为执行指令。
- 分别展示免费额度耗尽、来源不支持、页面禁止访问、没有结果等结构化停止状态。
- 搜索证据不能直接生成 Validated Need、合格贸易机会，公开邮箱不能标为已验证。

## 界面与兼容

指挥中心确认前展示线路、市场、预算、只研究模式；需求雷达、客户发现、Run Center 展示线路、来源证据、核验状态、额度消耗和停止原因。进口商候选与运输记录证据明确区分。

新增持久化配置、来源归属、额度记录的迁移均隔离租户。前端类型由 OpenAPI 生成。更新 ROADMAP、HANDBOOK、相关模块 AGENTS 和契约/工作流兼容 ADR；不更改 Phase 1 真实运营验收状态，不宣称整个 Phase 2 完成。

## 验收与运行边界

切片先失败测试后实现，顺序为契约/额度保护、三线路流程、界面接线、整体验收。覆盖：三线路可追溯闭环、跨线路与国家去重、无证据不推定进口/采购/OEM、并发额度耗尽、计费开启、用量失败、超时/限流及重启恢复无付费回退、研究模式零联系人/邮件/报价调用和原模式门禁、私网/越界重定向/登录墙/验证码/禁止访问阻断、凭证和原始敏感内容不进日志事件。

执行结构检查、相关与全量后端回归、前端测试、类型检查、构建和浏览器验收。三类公开页面真实联网证据与受控联系人/邮件/回复/需求验证/接管测试分开报告。用户自行配置免费账户密钥引用和确认预算，不在对话中传密钥；未配置则真实 Tavily 联网验收标为 `not_run`。免费限制只针对新增搜索/数据来源，模型和基础设施成本另记。
