# connectors/web_search/ —— 公开搜索（Phase 1）

## 能力范围

公开网页搜索、页面读取（带快照与哈希）。需求信号发现与企业发现的主要数据入口。

## 密钥归属

`WEB_SEARCH_API_KEY_REF`。

## 铁律

读到的每个页面产出：正文、URL、观察时间、内容哈希、快照 artifact 引用。**没有哈希的页面证据等于没有证据**——所有下游（信号、假设、候选）都依赖这四件套。

## 公开来源限制

页面/robots只通过安全HTTP传输，逐跳URL/DNS/实际对端校验，redirect限定原origin。
robots允许不是访问许可；国家政策/Playbook授权仍由Gateway守卫。robots失败、禁止、
未支持限制、明确站点deny、登录墙/验证码拦截均关闭。普通公开页登录导航/验证码表单
组件不单独触发误拒。拒绝内容页面不得写入快照；禁止任何登录或反爬绕过。
