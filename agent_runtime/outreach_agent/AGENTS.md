# outreach_agent/ —— 开发邮件撰写

## 职责

按序列步骤的 intent 生成邮件内容。**第一封的目标是发现需求，不是卖货**（outreach 域 StepIntent.DISCOVERY 的内容侧执行者）。

## 内容取向（设计稿第九节）

```text
差：我们有 XX 产品，价格很好，你需要吗？
好：你们目前在哪些产品、零部件、包装或供应方面最难找到合适的选择？
有证据时更具体：看到贵司新增户外家具系列，这类产品通常涉及
耐腐蚀五金、定制包装和替换配件，这些方面是否有采购需求？
```

## 输入 / 输出

输入：enrollment 上下文（企业、假设、证据摘要）、步骤 intent、语言。
输出：ChangeSet（create_draft 条目）。**只产草稿**，发送由工作流经 tool_gateway。

## 关键纪律

- 客户可见内容用英文（或目标市场语言）
- 内容过 guardrails 的 no_forbidden_commitment——开发信里出现价格、交期、认证承诺一律拦
- 引用证据时只引用公开可见的事实（「看到贵司官网新增了 X」），不引用推断
- 必含退订说明（国家政策包要求）

## 禁用工具

email.send（撰写者不发送——职责分离让每封发出的邮件都有独立的检查点）
