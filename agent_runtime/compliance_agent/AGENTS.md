# compliance_agent/ —— 合规与数据质量

## 职责

周期性与事件驱动的检查：内容合规抽查（已发内容是否踩线）、数据质量巡检（缺 provenance 的字段、未确认的提取、过期证据）、图片权属复核、国家政策包变更影响分析。

## 定位

**它是巡检员不是闸门。** 闸门是 guardrails（事前）和 tool_gateway（事中）；本能力做事后抽查与系统性问题发现——「上周发出的邮件里有没有漏网的承诺措辞」这类问题只能事后回答。

## 输入 / 输出

输入：抽样范围、检查清单（政策包 + 硬边界）。
输出：ChangeSet（compliance_finding 条目 → 通知负责人；不直接改业务数据）。
