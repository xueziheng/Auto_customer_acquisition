# 企业资料受控评估

本组样本与候选输出全部是合成资料，不包含真实企业内容。执行命令：

```bash
python -m pytest tests/evals/enterprise_knowledge -q
```

测试使用内存 CandidateModel，把固定候选输出送入当前资料分析能力和 Markdown 投影。不会调用 Codex、DeepSeek、网络、数据库或邮件。它验证确定性契约，不提供真实模型准确率、提示注入抵抗率、OCR 准确率或企业隔离部署验收结论。调用次数是测试替身次数，不是付费模型调用。

每个样本目录包含 input.json 与 expected.json。input 中 candidate_response 为人工编写的候选模型输出；parse_warnings 为可信解析器的独立提醒；foreign_context_not_available 只供构造对抗候选，绝不能传入请求上下文。图像使用一个内存 PNG 占位，重点验证来源类型、图像序号及原文件页码映射，不声称 PNG 中实际含有候选转录文字。

覆盖行为：

- 有引文的规格保留原文值；没有原文依据的规格拒绝。
- 上传资料中的命令保持为请求的数据内容；候选输出新增执行动作字段时拒绝。符合契约的提取仍须管理员确认，不能自动形成对外承诺。
- 解析提醒独立于原件正文，引用提醒作为产品事实时拒绝。
- 视觉转录标明 AI 来源；图像推断与转录分开；图像序号映射到原 PDF 页号，越界引用拒绝。
- 候选输出声明其他企业身份，或引用本次上下文没有的其他企业资料时拒绝。

边界：连续子串校验不能判断原文断言真假，也不能可靠区分伪装成规格的注入文字与真正产品规格。如果攻击文本本身包含某断言，模型逐字引用可能符合本契约；它仍是待人工确认的草稿。标题或推断中的任意语义泄漏不能仅靠本组测试证明已阻断，企业隔离还必须由受信身份、租户查询、RLS 和任务工作区保证。

视觉来源目前保留整个版本的 image_source_pages 映射及推断的 image_pages 引用；不具备逐句转录坐标或每条文字事实的独立页码。因此这里不声称转录每句话已与原件逐项定位。

样本遵守 tests/AGENTS.md：历史样本只增不改。后续更换 prompt 或模型时重跑本组；真实模型评估另记执行范围、费用与结果，不能以这些替身结果代替。
