# 普通业务来信受控候选契约评估

本组按企业资料既有CandidateModel方式，把固定候选响应送入真实BusinessMailClassifier及其输入/输出护栏。所有样本均为人工合成，不连接QQ、Codex或模型Provider，不产生费用或业务操作。

覆盖普通陌生询价、供应商报价、模糊意向、非业务内容、退订、自动回复、恶意操作指令、伪造来源引句、越权字段、概率字段、最终价格字段以及正文凭证标记。归类始终只是推断，候选不能授予已验证联系人、需求或商机；退订样本的review不代表已执行抑制操作，自动回复的other不代表已验证不存在采购需求。

这些样本验证固定JSON契约、必要上下文、逐字原文证据和确定性护栏，预置的category是受控候选，不是实际模型对样本的预测。因此通过结果不能用作模型准确率、提示词语义质量或真实业务验收的证据。实际模型对退订、自动回复与恶意指令的识别质量仍需单独、经授权评估。

执行：`python -m pytest tests/evals/business_mail -q`。样本只追加，不修改其他既有评估样本或全库历史样本计数断言。
