# infra/pilot：持久化本机 Web 内测基础设施

遵守根九条硬边界和 infra 规则。本目录只承载私有 profile、独立持久卷、精确资源生命周期及冷备份恢复；
不得导入 apps、创建 Employee 或业务种子。政策由操作者完整显式提供并复用领域类型校验，不提供业务默认。

配置目录 0700、文件 0600、当前 owner，拒绝软链接及多硬链接私有文件。技术凭证只在私有文件和进程中；
不得输出配置、Docker Env、DSN、原异常或原始资料。Docker 仅固定本机 socket 和已有精确镜像，不 pull。
所有资源动作先锁 profile、核验 owner 标签、精确容器 ID、卷身份和挂载；停止不删除容器或卷。
冷备份要求全部应用和存储静止；恢复仅新目标、新 owner，保持业务 ID 和 bucket/key，并撤销恢复会话。
